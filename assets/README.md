- `reinh_case-02_invoiceflow_1200x900_v1.png` - Telegram 4:3, LIGHT.

- `reinh-avatar-512.png` и `reinh-avatar.svg` - квадратный исходник аватара, рассчитанный на круговое кадрирование.
- `reinh-wordmark-light.svg`, `reinh-wordmark-dark.svg`, `reinh-wordmark-mono.svg` - прозрачные SVG с неизменными буквами в контурах и уточнённым Checkpoint: один поворот, один квадрат. Шрифт для отображения не нужен. Если мотив уже есть в композиции, скрыть/удалить группу `checkpoint`, оставив `wordmark`. Dark-версия - только на тёмном фоне.
- `reinh-tokens.json` - машинная копия секции токенов основного документа.
- `source-images/` - исходные изображения из публичных репозиториев для новых композиций; ссылки с commit IDs находятся в `../RESEARCH_NOTES.md`.

Обложки показывают опубликованные автором демо-материалы. InvoiceFlow использует два увеличенных crops одного снимка; Kontor - крупный crop подтверждения и отдельный crop календаря, не один синхронный сеанс. Координаты crops зафиксированы в шаблоне. Содержание не перекрашено и не перерисовано; исходники сохранены без изменений. На каждой обложке один Checkpoint, footer REINH без второго маршрута.

PNG экспортированы в исходных размерах, без перспективы. SVG можно размещать в редакторе макетов и на сайте; сохранять пропорции и охранное поле. В шапке сайта wordmark использовать шириной от 88 CSS px; для favicon - R.
